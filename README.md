# Lylac Jewels Inventory and Order Management System

**Name:** Jash Jivani  
**Course:** CINF 405 — Advanced Concepts and Practices in Software Development  
**Project:** Individual project

## Description

Lylac Jewels is a small jewelry business owned by my sister. This project is a planned web application to help the owner manage jewelry products, stock quantities, customers, and orders through a private dashboard.

The system will allow the owner to sign in, add and update products, adjust inventory, record orders, and track their status. When an order is confirmed, the system will check that every item has enough stock before reducing inventory. Online payment processing and a mobile application are outside the initial scope.

## Technologies and tools

- Python and Flask
- HTML and CSS
- SQLite
- JavaScript for optional interface enhancements
- Git and GitHub
